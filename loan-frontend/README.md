# Loan Approval Prediction - React Frontend

1. Install Node.js (v18+): https://nodejs.org
2. Open this folder in a terminal (or VS Code terminal)
3. npm install
4. npm run dev
5. Open http://localhost:5173

Backend (Spring Boot) URL is set in .env (VITE_API_URL).
If the backend is not running, the app decides locally so you can still demo it.
